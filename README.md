# Allesia

Весёлая анимация имени Allesia: танцующие буквы, конфетти, режим «драма» и неожиданные реакции. Поддерживает мобильные экраны, управление с клавиатуры, паузу и настройку уменьшения движения.

## Локальный запуск

Зависимости и сборка не нужны:

```sh
python -m http.server 8000
```

Откройте `http://localhost:8000`.

## Vercel

Импортируйте этот репозиторий в Vercel. Framework Preset: **Other**, Build Command: пусто, Output Directory: корень проекта. Анимация открывается на главной странице.
